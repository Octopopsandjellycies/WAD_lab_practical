# 🎓 Student Registration Portal (Bootstrap Dashboard)

A responsive **web application dashboard** built using **Bootstrap 5**.
This project demonstrates the use of **Bootstrap grid system, components, and form controls** in a structured layout for a lab exam.

---

## 🚀 Features

* Fully responsive layout using Bootstrap Grid
* Modern UI with cards and shadow effects
* Navigation bar with collapsible menu
* Hero header with gradient background
* Interactive form controls:

  * Dropdown (Select menu)
  * Radio buttons
  * Toggle switches (Checkboxes)
* Submit button with alert feedback
* Clean and minimal design

* Submit button triggers a simple JavaScript alert:
